Filosofía y Modelo de Ejecución1. **Invariante Zero-Allocation (GC-Free)**: Durante los ciclos continuos de ejecución (`tick()`, `render()`), está terminantemente prohibido instanciar objetos en el Heap. Toda la memoria se preasigna al inicio o se gestiona en buffers planos contiguos.2. **Soberanía del Lenguaje**: Toda la lógica de componentes, cálculo matricial, diseño de interfaz y respuesta al usuario se escribe en **código puro PhasorLang (`.ph`)**.3. **PVM Virtual Hardware Registers**: El entorno anfitrión (Web Canvas, Android Surface o Desktop Nativo) actúa únicamente como puente transparente de E/S mediante los registros `R0..R255`.---## 2. ## 16. Catálogo de Librerías Modulares BOM (Lista de Materiales por Grados)

Cada librería `.ph` está organizada por grado de complejidad y puede importarse directamente en cualquier aplicación:

| Grado | Archivo Librería | Función Principal | Propósito |
| :--- | :--- | :--- | :--- |
| **Grado 0** | `lib/core/primitives.ph` | `prim_box`, `prim_stroke`, `prim_glyph`, `prim_wrap` | Materia prima gráfica y aritmética toroidal Zero-GC. |
| **Grado 1** | `lib/ui/label.ph` | `ui_label(str_id, x, y, sz, color)` | Etiqueta tipográfica alineada. |
| **Grado 1** | `lib/ui/button.ph` | `ui_button(...)`, `ui_hit_test(...)` | Botón interactivo atómico con borde y detección de toque. |
| **Grado 1** | `lib/ui/tree_node.ph` | `ui_tree_node(...)` | Nodo de árbol jerárquico con icono por extensión y botón contextual (`⋮`). |
| **Grado 2** | `lib/ui/explorer_toolbar.ph` | `ui_explorer_toolbar(ox, oy, ow, mx, my, click)` | Barra superior estilo VS Code (`Abrir`, `Proyecto`, `+Archivo`, `+Carpeta`, `GitHub`). |
| **Grado 2** | `lib/ui/popup_menu.ph` | `ui_popup_menu(...)` | Menú flotante contextual por archivo (`Editar`, `Importar`, `Renombrar`, `Eliminar`). |
| **Grado 2** | `lib/ui/hud_topbar.ph` | `topbar_render`, `topbar_handle_click` | Barra superior fija de navegación (`S1..S4`) y conmutador Móvil/Escritorio. |
| **Grado 2** | `lib/ui/hud_dpad.ph` | `dpad_render`, `dpad_handle_click` | Controlador direccional flotante con minimapa toroidal 2x2. |
| **Grado 2** | `lib/spatial/gesture_lock.ph` | `torus_step`, `torus_goto` | Navegación toroidal 2D con Deadzone de 14px y Axis-Lock ortogonal. |
| **Grado 3** | `lib/screens/screen_explorer.ph` | `screen_explorer_full(...)` | Explorador completo con `OPEN EDITORS`, árbol BOM y señal puente `editor_active_file_id`. |
